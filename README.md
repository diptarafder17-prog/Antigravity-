# Antigravity-

A lightweight static landing page project for showcasing product-style concepts and experiments.

## Project overview

This repo contains a simple HTML/CSS landing page and concept pages built as part of a design/demo workflow. It is intentionally minimal and easy to extend.

## Files

- `index.html` — main landing page
- `style.css` — shared styling
- `script.js` — page scripts
- `kiwvy.html` — additional concept page

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.

Example:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This project was created as a simple front-end prototype and can be expanded with more pages, sections, or interactive content.
